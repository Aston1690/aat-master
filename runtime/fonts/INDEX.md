# Team font library

Official Google Fonts files, unchanged, each folder with its licence (all open licences that allow sharing), METADATA.pb and SOURCE.txt.
`py -3 tools/design.py fonts <client> "<Family>"` copies a family from here into the client's brand folder with no download.
Add a family for everyone: `py -3 tools/design.py fontlib add "<Family>"`, then commit `fonts/` through a pull request.
