# Rejection lessons — owner change queue

No client rejection entry is asserted by this template. Keep the actual client identity, contacts, palette and raw feedback in the client folder. Use a neutral job reference here; GitHub entries carry only the general rule and evidence needed for owner review.

| Neutral lesson ID | Rejection date | Skill | General failure / proposed rule | Named owner | Due within one week | Owner-reviewed GitHub change | Outcome / adoption date |
|---|---|---|---|---|---|---|---|

Agents record proposed lessons in job notes. The human owner brings the generalised change through GitHub within one week and records review/adoption. Monthly review checks overdue lessons and removes rules that no longer earn their place. Do not claim an empty queue proves that no rejection occurred.
